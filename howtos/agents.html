Use codeps with an AI agent 🔗

Install the skill 🔗

Install the Codeps skill from your project directory:

npx skills add sake92/skills --skill codeps

Select your coding agent in the installer. Add -g to make the skill available across your projects. See the skills installer documentation for supported agents and installation options.

Ask for an analysis 🔗

Open your project in the coding agent and give it a prompt such as:

Use the codeps skill to analyze this codebase. First configure codeps for this project, or verify its existing configuration: select the correct dependency producer, project root, fresh build inputs, and include/exclude rules so the analysis covers our code. Assess the package-per-feature structure: whether related feature code belongs together and dependencies between features are clear. Find dependency cycles, the messiest parts, and quick wins for simplification. Rank the findings by likely impact and effort, with concrete files or packages and evidence for each. Analyze and recommend changes first.

The skill guides the agent through choosing dependency inputs, building the project, running codeps, and inspecting relevant findings. It includes a runner for the supported CLI version. If your project needs input setup or the build fails, the agent should explain what is missing and which conclusions it cannot verify.

Follow up on a finding 🔗

Choose a recommendation and ask the agent to implement it:

Implement the smallest change that breaks the cycle you identified. Rebuild, run the relevant tests, and use codeps to verify the cycle is gone. Show the before and after evidence.

For manual analysis commands, see the CLI reference and package triage tutorial.
