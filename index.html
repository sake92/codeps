codeps 🔗

codeps is a code package dependency analyzer for JVM projects (Java and Scala). It parses existing compiler output — SemanticDB or jdeps — and produces a package-level dependency graph, which you can export as DOT, JSON or Mermaid.

No build-system integration needed: it just reads what your compiler already produced.

New here? Start with the Quickstart. Want to explore a graph interactively? Try the interactive demo — it loads graphs exported with -f json.

Features 🔗

  • Two input formats:
    • SemanticDB — detailed, from Scala compiler output (.semanticdb files), with per-package file/class stats
    • jdeps — from the JDK's own jdeps -verbose:package output, no extra tooling needed
  • Filtering — keep only packages matching --include patterns, drop noise with --exclude (e.g. java.*, scala.*)
  • Collapsing — merge whole package subtrees with --collapse rules (com.example.**, org.lib.*)
  • Three export formats — DOT, JSON, Mermaid
  • Interactive demo — a standalone graph viewer: layouts, filtering, degree analysis, package suggestions

Quick example 🔗

deder exec -t run -m cli semdb tmp/examples/example1/classes/META-INF/semanticdb -i com.example -f dot

digraph deps {
  "com.example.app" -> "com.example.modules.module2";
  "com.example.modules.module1" -> "com.example.util";
  "com.example.modules.module2" -> "com.example.modules.module1";
}
