codeps 🔗

codeps tracks broad dependency-health trends for JVM projects. It reads compiler output, identifies cycles and coupling signals, keeps compact history, and generates a static dashboard for each configured project.

Configure the repository once, then run one command in CI:

codeps status

The command writes:

  • .codeps/<project>.ndjson — compact history intended for Git.
  • .codeps/out/<project>/report.json — latest detailed report.
  • .codeps/out/<project>/index.html — interactive D3/Pico dashboard.

Use codeps inspect-cycle or codeps inspect-node to drill into a saved report after the dashboard identifies something worth investigating. The report is a trend signal, not a substitute for architectural judgment: its metrics are intended to be good enough to reveal a direction of travel.

See the CLI reference for the repository configuration and GitHub Pages workflow, Tutorials for guided setup, and How Tos for SemanticDB and jdeps input.
